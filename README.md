
🎯 Analytics report using supervised learning to identify customer churn in a telecommuncation company with 85% Recall using Gaussian Naive Bayes Machine Learning Model. The report also identifies main reasons for churning and uses machine learning to identify target customers for proactive approach for churn reduction.

🔑 Churn is a very important indicator for telecommunication companies since it is much more expensive to attract new customers than to retain existing ones. This report focus in two specific tasks:
1- Identifying the main reasons for churn in this telecommunication company through exploratory data analytics.
2- Identifying customers with potential for churning, so that a strategy can be developed and addressed to these customers.

🧠 In this project 6 machine learning algorithms are performed, namely Gaussian Naive Bayes, Support Vector Machine, KNeighbors, Random Forest, Deicison Tree and Logistic Regression, with SMOTE technic for rebalancing the dataset, together with GridSearchCV for CrossValidation and Hyperparameter tunning, aiming to increase recall even when precision is sacrificed. Improvements on the model could be achieved using customer segmentation, and performing separate analyses for different segments.
